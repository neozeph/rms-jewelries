TC-INQ-001
Title: Submit valid jewelry inquiry

Precondition:
Published jewelry exists.

Steps:

1. Open jewelry detail page.
2. Click "Inquire About This Piece".
3. Enter valid customer information.
4. Enter inquiry message.
5. Submit.

Expected:
Inquiry is successfully submitted.
Success confirmation appears.
Customer record exists.
Inquiry record exists.
jewelry_id references correct jewelry.
